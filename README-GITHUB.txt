حزمة ملف الإنجاز المخصصة لـ GitHub

- ضعي جميع الملفات الموجودة في هذا المجلد في جذر المستودع.
- يجب أن يكون index.html في المستوى الأول مباشرة.
- مجلد assets يجب أن يبقى باسم assets كما هو.
- الشواهد في صفحة الإدارة أصبحت روابط فقط (اسم الشاهد + رابط Google Drive).
- بعد رفع هذه الملفات إلى GitHub، سنربط نفس مشروع Netlify بهذا المستودع حتى يصبح النشر تلقائيًا عند تحديث المستودع.
- ملاحظة: زر الحفظ داخل صفحة الإدارة ما زال مؤقتًا ينزّل data.js. بعد إكمال ربط GitHub سنحوّل الحفظ إلى مسار مباشر وآمن بدل رفع ZIP.
