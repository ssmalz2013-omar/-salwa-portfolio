حزمة ملف الإنجاز النهائية — GitHub Pages

هذه النسخة مخصصة للرفع مباشرة إلى مستودع GitHub.

طريقة الرفع:
1) ارفعي جميع الملفات والمجلدات الموجودة داخل هذه الحزمة إلى جذر المستودع.
2) يجب أن يكون index.html في المستوى الأول مباشرة.
3) اتركي مجلد assets كما هو ولا تغيّري اسمه.
4) من GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
5) اختاري branch: main و folder: /(root) ثم Save.

صفحة الإدارة الخاصة:
- salwa-admin.html
- منها يمكن تعديل البيانات ثم الحفظ مباشرة إلى data.js في GitHub.

ملاحظة أمان:
- لا تضعي رمز GitHub داخل أي ملف من ملفات الموقع.
- أدخليه فقط داخل صفحة الإدارة عند الحاجة.
